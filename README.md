# 番茄小说纯净版

基于 [ch6vip/fqapp](https://github.com/ch6vip/fqapp) 的小说专用 Android 客户端。
仅提供小说书城、搜索、书架、阅读与离线下载，不加入短剧、视频、漫画、听书或 AI 功能。

[下载最新 ARM64 APK](https://github.com/GodBook/fanqie-pure-reader/releases/latest) ·
[反馈问题](https://github.com/GodBook/fanqie-pure-reader/issues)

## 安装与在线更新

支持 Android 7.0（API 24）及以上的 ARM64 手机。首次安装请从 Releases 下载 APK，按系统提示安装。
以后在底部“设置 → 软件更新”检查、下载并安装新版本。安装需在系统安装器确认；
部分系统需要先允许本应用安装未知来源软件，返回后再点击“安装更新”。

下载使用 HTTPS，并校验文件大小与 SHA-256；交给系统安装前再次校验哈希、包名、递增版本号及签名。
版本检查和附件下载使用 GitHub 官方 Releases API，无需登录或令牌。
取消或失败可重试。更新沿用相同签名，保留书架、阅读进度和已下载章节。
更新依赖手机能访问 GitHub；网络不可达时可稍后重试或打开发布页面手动下载。

## 功能

以下为当前源码包含的功能，公开版本以 Releases 为准。

- 书城优先显示本机加密书目快照；首次安装显示经官网核实的公开书目，后台获取最新推荐。
  首屏可直接点击书籍，不等待推荐网络请求。缓存/内置书目有明确提示，它们不代表最新联网推荐已完成。
- “设置 → 找书偏好 → 个性化推荐”默认开启，按本机书架与阅读记录中可识别的题材，调整已加载且符合筛选的部分候选小说顺序；没有可用题材时保持原顺序，手动指定的排序优先。
  兴趣计算在本机进行，不将书架或阅读记录作为兴趣数据上传。关闭后不使用本机兴趣，并向上游推荐和搜索请求发送关闭标记；服务端如何处理由上游决定。
- 分类、评分门槛、连载/完结及高分/长短篇排序，偏好持久化，未知评分不冒充高分。
  评分支持不限及7.0–9.9分，每0.1分一档，书城与搜索共用。
  可按字数区间筛选、隐藏已在书架或有阅读记录的作品，并在本机保存命名找书方案；启用字数区间时排除未知字数。
  筛选与排序只作用于已加载的候选书目，不代表全站排序。
  内置书目不覆盖所有严格筛选组合；无匹配时仍需联网获取，不以无关书籍填充。
  10分钟内切回已加载分类可直接恢复书目及分页位置；筛选找到首批匹配后即可结束本批等待。
- 搜索书名、作者或编号，真实联想、精确/相近结果、分页、筛选与历史记录管理。
  书名和作者支持本机模糊、全拼和首字母匹配，范围包括番茄书架、最近 300 条阅读记录、已浏览书目、本机书城缓存和内置书目；离线也可使用本机匹配。
  已浏览书目的加密索引最多保存 1,500 本，全局本机匹配最多返回 40 条，多音字读音以拼音字典为准；在线搜索仍向上游发送原关键词。
  全局本机匹配不包含导入的 TXT/EPUB，也不覆盖全站；导入书可在书架内按书名或作者匹配。
  搜索框支持官方长链接 `https://fanqienovel.com/page/书号`，提取书号后查询；不展开短链或接收系统分享。
  全部分类中的标签用于分类关键词搜索，结果按相关性展示；可继续使用评分和连载状态筛选。
- 详情简介、可搜索/倒序目录、真实评分书评与相关推荐。
  真实标签可用于关键词搜索，搜索结果不限定标签。
- 真实小说排行榜支持榜单与题材切换，显示书籍真实评分，缺失时补查详情，仍不可用则显示“暂无评分”；缓存注明保存时间。
- 书荒广场：真实读者求书话题、荐书正文与对应小说，每位书友的荐书横向排列并可左右滑动，热门/最新、分页与刷新；只读浏览。
  话题可本地收藏，离线查看已保存摘要及缓存时间；获取最新荐书仍需联网。
- 底部书城、书架、设置三个栏目；设置按外观阅读、下载追更、阅读数据及应用信息分组。
- 本地书架分组、多选管理、排序、阅读历史及续读位置，支持书架内搜索、阅读状态和置顶；独立追更中心集中查看更新。
  当前分组的可核实记录提供“接着读”入口，空书架可直接搜索小说。
  缓存目录先进入阅读，联网后后台校验新章节，也可在阅读更多菜单刷新目录。
- 分页/滚动阅读、字体字号、行距、背景、亮度、音量键翻页、书签、划线与笔记。
  可跨已缓存章节查找，搜索不会自动下载未缓存章节；标注支持搜索、按章节排序及选择导出 TXT/Markdown。
  单书字号、行距和翻页方式可继承或覆盖全局设置，也可保存命名阅读配置。
  阅读上栏可直接加入书架，并显示当前收藏状态。
  阅读菜单和书架续读卡显示全书进度条及“本书已读”百分比，按当前目录与章内位置估算；跳章和连载新增章节可能改变比例，不代表实际已读文字的覆盖率。
  同一原文位置可分别保存多条笔记；划线达到2000条时提示管理，不自动删除旧标注。
  笔记保存失败或原文变化时保留草稿；书签、笔记分别筛选。目录、查找和标注跳转后可返回原阅读处。
  邻章同屏显示范围划线，跨段摘录保留换行。
  长按按词选中，支持拖动调整至单字边界、选择整段；复制保留选区原文并反馈结果，失败可重试。
  选中文字可交给系统文本应用，或主动打开有道词典/必应翻译网页；仅发送所选短文本，不发送整章，网页查询需要联网。
- “设置 → 阅读报告”提供月度/年度总结，包括前台时长、阅读天数、读过书数、时长分布和分书排行；也可查看今日、近七天及周记录。
  报告使用本机已有记录，不推断未记录历史或读完书数；写入时最多保留最近 730 个有记录的日期，更早记录会清理，并非完整历史档案。时长可能包含静置。休息提醒默认关闭，可在设置中启用。
- 段评、章评和回复浏览，失败重试与段评显示开关；段评图标尺寸不变，触控区扩大到44dp。
  上游评论接口为只读。
  查看评论时暂停自动翻页；评论字号可跟随正文或单独设置，原文摘录可展开，正文段评有独立读屏入口。
  评论默认使用独立 16 pt，评论列表底部空白已修复。旧版“跟随正文 + 独立字号为 18 pt 或未保存独立字号”的组合会迁移为独立 16 pt；旧版无法区分默认和手动选择，升级后可重新选择跟随正文。
- 暖白、墨灰与柔和朱红的日间/夜间配色，支持系统文字缩放。
  “设置 → 主题颜色”可选朱砂、松绿、靛青、湖蓝、藤紫和琥珀，选择自动保存，可配合日间、夜间或跟随系统使用。
  大字号下书目信息可换行、操作移到封面下方；字号与行距可用加减按钮调整，减少动态效果时不播放页面过渡。
- 从当前章或指定范围下载，使用前台顺序队列，支持暂停/继续、失败重试与重启恢复；已下载章节离线可读。
  小说插图保存到独立离线目录；列表分别显示正文和插图状态，可补存已下载章节插图，图片失败不删除正文。
  原续读章节未下载时先选择联网续读或已下载章节，取消会保留原进度；自动补更保留暂停任务入口。
- 应用前台按网络偏好检查下载书籍，只补新增章节；可关闭自动追更。
- 离线空间总览提供分类统计、受保护的批量清理和软预算提醒，超过提醒阈值不会自动删除；正文按逻辑字节统计，不等于实际磁盘占用。
- 系统文件选择器备份/合并恢复书架、分组、进度及标注，可选阅读偏好与新增功能数据，恢复前可逐书选择如何处理进度冲突；不导出设备身份或正文。
  最多保留 5 份本机快照，卸载或清除数据时会删除，请另存外部备份。
- 支持导入本地 TXT（包括 UTF-8、GB18030）和无 DRM EPUB，单个文件不超过 32 MiB，EPUB 解压后不超过 64 MiB；导入后可离线阅读。
  阅读备份不包含本地书文件，请自行另存，迁移时在目标设备重新导入相同文件以关联阅读数据。

在线内容直接使用上游接口，无需自建内容服务器或 root；接口变化会影响在线功能。
书架、设备身份、缓存与阅读数据在本机保存，不上传到项目仓库。
联网请求会按上游协议向内容服务发送必要的设备标识；本项目没有自建数据收集服务。

## Windows 构建

工具链：Flutter 3.47.1 / Dart 3.13.1、JDK 17、Android SDK 36、NDK 28.2.13676358、
Rust（`aarch64-linux-android` 与 `armv7-linux-androideabi` 目标）、PowerShell 7.2+。

```powershell
flutter pub get
pwsh -File scripts/build_novel.ps1 -BuildMode release -JdkRoot C:\tools\jdk-17 -BuildRoot C:\src\fanqie-pure-reader
```

`BuildRoot` 请使用当前检出的源码目录，Windows 建议英文路径。
缺少 Rust 原生库时脚本会构建；修改 Rust 后加 `-RebuildNative`。
仅打包 ARM64；构建产物位于 `dist/fanqie-pure-release-arm64.apk`，附 SHA-256 文件。

正式签名由脚本在本机构建者的 `%LOCALAPPDATA%\FanqiePure\signing` 创建并用 Windows DPAPI 保护口令。
自行构建的签名与本仓库发行版不同，不能覆盖安装发行版。后续自行升级必须沿用自己的密钥。
签名私钥、口令、设备注册池和私人缓存不得提交。

```powershell
flutter analyze --no-pub
flutter test --no-pub test/novel_fast_feed_test.dart test/novel_app_update_test.dart test/novel_catalog_test.dart test/novel_recommendation_filters_test.dart test/home_feed_cache_test.dart
```

完整小说设备测试：`integration_test/novel_workflow_test.dart`；
`scripts/test_novel_device.ps1` 使用独立 `.test` 包，需授权 ADB 与解锁手机。
离线续读保护专项真机测试：`scripts/test_novel_resume_safety.ps1`，在同一独立测试包的临时数据目录验证取消保留进度和明确选择章节。
阅读体验专项：`scripts/test_novel_reading_improvements.ps1`，在独立测试包验证笔记异常、标注、读屏语义和插图离线文件；正式包的联网正文及系统亮度另行实测。
不要在 Flutter 构建/真机驱动运行时并行执行 Flutter 单元测试。
发布方法见 [RELEASING.md](RELEASING.md)。
